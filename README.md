Most of my work lives in private repositories. What is public here is personal tooling.

- **Platform**: a family of internal Python/Flask services and the shared library behind them; engineering standards (backend, docs, Git, Python) across several teams.
- **Security**: secrets management and a trusted-network model, request classification with a machine-learning model, incident response and phishing investigations, GCP and Workspace audits, PCI SAQ, disaster-recovery planning.
- **Google Cloud**: App Engine, Cloud Run, Cloud Build, Pub/Sub, BigQuery, Datastore, Secret Manager and IAM across dozens of projects; proxy fleets rolled out to dozens of hotels; cost and project audits.
- **AI agents in production**: a company MCP server (Slack, Gmail, ClickUp, knowledge base), skills, protocols and telemetry for Claude Code and Codex, an LLM assistant for reservation email, RAG chat.
